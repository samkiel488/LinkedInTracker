# LinkedIn Rent Payment Tracker  

## Overview  
The **LinkedIn Rent Payment Tracker** is a web-based application designed to help you keep track of LinkedIn connection rent payments. With features like light/dark mode toggling, local storage for persistent data, and customizable input fields, this app ensures you can manage your connection packages effectively.  

## Features  
- **Dark Mode Toggle**: Seamless light and dark mode for comfortable viewing.  
- **Local Storage**: Save and retrieve data even after closing the browser.  
- **User-Friendly Form**: Add new entries quickly with an intuitive form.  
- **Payment Status**: Mark payments as "Paid" or "Not Paid" for better tracking.  
- **Data Management**: Edit or delete entries as needed.  
- **Responsive Design**: Works on both desktop and mobile devices.

## Installation  

1. Clone the repository:  
   ```bash
   git clone https://github.com/yourusername/linkedin-rent-tracker.git
   cd linkedin-rent-tracker

2. Open the index.html file in a browser to start using the application.



Usage

1. Add a new entry by filling in the form (Name, Start Date, Next Payment Date, and Package).


2. View all entries in the table, complete with their payment statuses.


3. Mark entries as "Paid" using the checkbox or delete them as needed.


4. Toggle between light and dark mode using the switch in the top-right corner.
